# Geography

`counties-10m.json` is the US Atlas TopoJSON (us-atlas 3.0.1, https://github.com/topojson/us-atlas, ISC license), derived from Census Bureau cartographic boundary files at 1:10m. Objects: counties, states, nation. County ids are 5-digit FIPS; state ids are 2-digit FIPS. Committed so the site never fetches it from a third party.
