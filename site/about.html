About

The federal workforce is the government. Its changes are public record, monthly, in files almost nobody can open. This site opens them.

What it is

A static dashboard over OPM's Federal Workforce Data, USAspending, and OMB's employment tables. Start government-wide, pick an agency to see people beside money, then walk down the org chart into personnel detail: headcount, hires, separations by category, grade and step mix, age, pay bands. Every chart has a data table behind it, and every month's cleaned data is downloadable.

What it is not

It is not a people-lookup tool. OPM's files carry no names, and this site adds none. It does not link the statutory list of political appointees and executives to workforce records, because that would re-identify people OPM deliberately de-identified.

Privacy

No analytics, no cookies, no accounts, no server. Pages load data from this site and from GitHub Releases, and chart libraries from a pinned CDN. Queries you run in the "Ask the data" panel execute inside your browser with DuckDB and never leave it.

Who

An Awry Labs project by Robert Hoekstra. Independent software, a little off on purpose. Not affiliated with OPM or any agency.

Reuse

The pipeline, site, and cleaned data are open. See Data for the schema and the methodology, and the repository for the code.
